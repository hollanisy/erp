📋 Langkah Setup (Cukup Sekali):

  1. 1Buka console.cloud.google.com → buat Project baru
  2. 2Aktifkan Google Drive API: APIs & Services → Library → "Google Drive API" → Enable
  3. 3Buat OAuth Consent Screen: pilih External → isi nama app → tambahkan scope drive.file → tambahkan email Anda sebagai Test User
  4. 4Buat Credentials: Credentials → Create Credentials → OAuth Client ID → pilih Web Application
  5. 5
    Tambahkan Authorized JavaScript Origins:
    https://drive.google.com
    http://localhost:8080
  6. 6Copy Client ID (format xxxxxxxx.apps.googleusercontent.com) → paste di kolom atas → Simpan

📌 Catatan:

  • Data disimpan di folder SyahirDocERP di Google Drive Anda — hanya bisa diakses app ini.
  • Semua data termasuk konfigurasi & logo disinkronisasi agar semua PC sama persis.
  • Client ID disimpan hanya di browser lokal Anda — tidak dikirim ke mana pun.
